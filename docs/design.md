# 阅读记录设计

用户确认 GitHub Pages + Supabase 免费同步方案。

阅读概览呈现本年读完次数、去重书数、在读数、平均阅读天数、月度柱形图、类型分布、正在阅读和最近读完。月度记录按完成日期列出阅读次数和书籍；书架按书籍汇总每次阅读与次数。跨年阅读计入完成年/月。

输入书名、常见译名或 ISBN，检索已有书架、本地常见书目、Wikidata 中文快照与在线 Wikidata/Open Library。已有个人信息和完整匹配优先；部分本地命中继续联网，完整命中可手动继续查找。ISBN 需通过校验位验证；选定匹配后使用真实书名。用户选择匹配后可改作者、分类，不能将无法匹配的分类伪装成确定结果。一次阅读有开始日期、可选完成日期、笔记；日期按本地日历天，含首尾，限制未来日期与结束早于开始。

图书和阅读次数分表。Supabase 登录通过邮箱密码；每个用户只能读写自己的行，阅读记录复合外键阻止引用别人的图书。未配置或未登录时本地模式独立存储，登录后显示云端数据，不自动上传本地数据。云端读写失败保留表单并提示，不宣称成功；切换账号清空旧视图。

支持导出 JSON，导入采用校验后追加，重复 ID 跳过，云导入在事务中完成。删除需确认。示例仅主动加载到本地空数据集。配置可由 config.js 固定或在浏览器设置，禁止管理员 key。GitHub Pages 使用相对路径、.nojekyll、静态资源，无需 Node 构建。

色彩：背景 #f5f7f4、主面板 #ffffff、墨色 #243b31、强调 #315e49、次文本 #66746a、分割 #e1e7df。中文系统无衬线用于界面，衬线用于书名；侧边栏是目录，月度图是首页主要图形。44px 操作区域，键盘焦点，移动端底部导航与单列布局。

验证覆盖跨月/跨年/闰年、同日阅读、重复阅读、空数据、恶意书名、备份校验、手机宽度、表单流程。云权限与多设备同步必须连接真实项目后验收。
